# Word Recall v0.6

GitHub Pages で動作する英単語学習アプリです。

## v0.6 の主な変更

### 画像を学習データ本体から分離
これまでの版も IndexedDB を使用していましたが、画像の Base64 データを単語・正解率・学習履歴と同じ `state` オブジェクトに入れて保存していました。
そのため、1問回答して正解率を保存するだけでも、大量の画像を含む巨大な state 全体を書き直していました。

v0.6 では IndexedDB 内を次の2ストアに分けます。

- `app`：単語、コアイメージ、例文、成績、復習予定などの軽量データ
- `images`：画像 Blob のみ（単語IDをキーに保存）

これにより学習中の正解率更新では画像を書き直しません。

### 既存画像は自動移行
v0.5以前で登録済みの画像は作り直す必要がありません。
初回起動時に、旧 state 内の画像を1枚ずつ `images` ストアへ移します。
各画像は「画像保存 + 旧stateからその画像を外す」を同一トランザクションで行うため、途中で閉じても次回起動時に続きから安全に移行できます。

移行時に画像の再圧縮はしないので、既存画像の品質は変わりません。

### 新規画像
新しく画像を登録すると、最大1200pxに縮小したJPEG Blobとして画像ストアへ直接保存します。

### 一括登録
画像なしJSONで既存単語を更新しても、すでに手動登録している画像は削除されません。
画像入りJSONの場合だけ、その単語の画像を更新します。

### バックアップ
「バックアップを書き出す」では画像もJSON内に埋め込むため、従来どおり1ファイルで復元できます。
復元時には画像を自動で `images` ストアへ分離します。

### v0.5の機能も維持
- 単語管理：アルファベット順 / 登録順 / Recall正解率順
- 昇順 / 降順切替
- 解答後の「次へ / 次の単語」ボタン大型化
- Recall画面の品詞表示
- 「わからない」ボタン
- 答え表示時の英語音声

## GitHubでの更新方法

1. 念のため、現在のアプリで「バックアップを書き出す」を1回実行してください。
2. このフォルダ内の次の5ファイルをGitHubリポジトリ直下へアップロードして上書きします。
   - `index.html`
   - `app.js`
   - `styles.css`
   - `ui-v0.6.js`
   - `README.md`
3. GitHub Pages の公開URLを再読み込みします。
4. 初回起動時に既存画像があれば自動移行されます。

**重要:** ブラウザのサイトデータを削除しないでください。GitHub上のプログラムファイルを更新するだけなら、現在の単語・成績・画像はそのまま残ります。
