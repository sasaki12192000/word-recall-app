# Word Recall v0.7.7

Sentence Recall を中心にした英語学習アプリです。既存カードの `sentenceJa` / `sentenceEn`、画像、カードID、学習履歴を維持したまま使えます。

## 学習モード

### 文脈タイピング
- 日本語例文 + 穴埋め英文 + 登録画像を表示
- 空欄に入る英語をタイピング
- 日本語例文では、空欄に対応する日本語を赤字で表示
- 正解表示では、正解・日本語コアイメージ（`core`）・完成英文を表示し、完成英文を読み上げ

### 自動瞬間英作文
- 既存の `sentenceJa` / `sentenceEn` を使用
- 画像は表示・読み込みしない
- 日本語を表示して日本語音声を再生
- 音声終了後、設定秒数だけ頭の中で英文を考える
- その後、英文を表示して英語音声を再生
- 答え表示中に「間違えなかった / 間違えた」を自己判定
- 英文の確認カウントが0になるまで未選択なら、自動で「間違い」扱い
- 時間切れ時に英語音声が再生中なら、判定は×に確定したまま音声終了後に次へ進む
- 自己判定は文脈タイピングと共通の Recall 正誤率へ反映

## v0.7.7 の学習セット仕様

1回の出題数で選ばれたカード（初期値20問）を、そのセッションの固定セットにします。

- 間違えなかった問題 → そのセッションでは出題終了
- 間違えた問題 → 次の周で再出題
- 2周目以降に新しいカードは追加されない
- 全カードが一度「間違えなかった」になるまでセッションを継続
- 画面上部に「残り X / 20・N周目」を表示

文脈タイピングの自動判定と、自動瞬間英作文の自己判定は同じ `stats.recall` の正誤率に集計されます。
自動瞬間英作文はタイピング時間を測定しないため、平均回答時間の計算からは除外します。

## データ保存

- 軽量な単語・学習データ: IndexedDB `app` ストア
- 画像: IndexedDB `images` ストア（カードIDをキーに保存）
- バックアップJSONには画像も含めて書き出し可能

既存のカードIDを変更しないため、アップデート時に登録画像を再登録する必要はありません。

## PCで試す

### GitHub Pages版をPCで試す
公開済みのWord RecallをPCのChrome / Edgeで開けば、そのPC専用の保存領域で試せます。iPhone側のデータとは別です。必要ならバックアップJSONをPC側へ復元してテストできます。

### GitHubへ上げる前にローカルで試す
このフォルダでターミナルを開き、Pythonが入っている場合は次を実行します。

```bash
python -m http.server 8000
```

その後、PCブラウザで `http://localhost:8000` を開きます。

> `index.html` を直接ダブルクリックするより、ローカルHTTPサーバー経由の確認を推奨します。
