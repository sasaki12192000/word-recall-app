# Word Recall v0.7.8

文脈の中で英語を思い出す、GitHub Pages対応の英語学習アプリです。HTML・CSS・JavaScriptだけで動作し、サーバー側のデータベースやアカウントは不要です。

## v0.7.8 の変更点

- 自動瞬間英作文の確認時間が0秒になっても、自動判定・自動進行しません。
- ○ / × を選択すると、残り時間や音声終了を待たずに次の問題へ進みます。
- 両学習モードで初回の出題カードを固定し、正解したカードはそのセッションから除外します。
- 上部に周回数・クリア済みカード数・残りカード数を表示します。
- 二重判定、連続した進行操作、前の問題の音声イベントによる誤進行を防止します。
- 完了画面から再読み込みなしで次のセッションを開始できます。
- 保存データの読み込みに失敗した場合は、空のデータで上書きしないよう操作を停止します。

## 学習モード

### 文脈タイピング

1. 日本語例文・穴埋め英文・登録画像（ある場合）を表示します。日本語の正解対応箇所は、`clozeJaTarget` が登録されていれば赤字表示します。
2. 空欄に入る英語を入力して Enter または判定ボタンを押します。「わからない」も選べます。
3. 正誤・正解・日本語コアイメージ・完成英文を表示し、完成英文を読み上げます。
4. もう一度 Enter または「次の問題」を押すと次へ進みます。

同じ入力要素を保持し、ボタン操作でフォーカスが失われにくい既存方式を維持しています。iPhoneのソフトウェアキーボードの挙動はOS・Safariの仕様にも依存します。

### 自動瞬間英作文

1. 日本語例文を表示し、日本語音声を再生します。
2. 日本語音声終了後、設定した3・5・7・10秒のカウント中に頭の中で英作文します。
3. カウント終了後、日本語の下に英文を表示し、英語音声を自動再生します。
4. 「○ 間違えなかった」「× 間違えた」を押して自己判定します。英文確認カウントは3・5・7・10秒から設定できます。
5. 確認カウントが0秒になっても、英文と判定ボタンを表示し続けます。未判定のまま不正解になったり次へ進んだりすることはありません。
6. 判定ボタンを押した瞬間に判定を1回記録し、古い音声・タイマーを停止して次の日本語へ進みます。全問クリア時は完了画面を表示します。

このモードでは画像の取得・表示を行いません。読み上げにはブラウザの Web Speech API を使用します。利用可能な音声や自動再生の可否は端末の設定に依存します。日本語音声の終了イベントが来ない場合は既存の安全用タイムアウトから考える時間に進みます。

## 出題・復習ロジック（両モード共通）

- 出題数は10・20（初期値）・30・対象すべてから選択できます。
- 日本語・英文の両方を持つカードのうち、通常は復習日が到来したものが対象です。「復習日前の単語も追加練習する」をONにすると復習日前のカードも含めます。
- 対象カードをIDで重複排除し、共通Recall正答率が低いほど選ばれやすい重み付き抽選（非復元抽出）を開始時に一度だけ行います。未回答は正答率0%相当、重みは1～10です。復習日は対象判定に使い、対象内の抽選重みは正答率で決めます。
- 対象が設定数に満たない場合、利用可能な枚数で開始し、実枚数を表示します。設定数を満たすために同じカードを重複させたり、復習日前のカードを無断追加したりしません。
- 最初のID一覧を固定し、未クリアID集合から正解したIDだけを削除します。2周目以降はその未クリアIDだけを初回の順番で出題します。途中で新しいカードは追加しません。
- 全カードが一度正解になるまで周回制限なしで繰り返します。途中終了した場合は、それまでの回答履歴を保持しますが、セッション自体は再開されません。

例：10問設定 → 1周目6問正解・4問不正解 → 2周目3問正解・1問不正解 → 3周目1問正解 → 10問完全クリア（計15回答）。

上部表示例：`2周目 ｜ クリア 6/10 ｜ 残り 4`。クリアと残りは初回カード枚数を基準にし、合計回答回数とは区別します。

両モードは既存の `stats.recall` を共用します。正誤を各1回記録し、既存のLevel・次回復習日の更新規則（正解でLevel+1、誤答でLevel-2、範囲0～7）を維持します。自動瞬間英作文の回答は平均タイピング時間に含めません。

## データ保存と既存データの互換性

| 保存先 | 内容 |
| --- | --- |
| IndexedDB `WordRecallDB`（version 2）・`app` ストア・`state` キー | ID、単語・チャンク、例文、穴埋め、日本語コアイメージ、画像有無、学習履歴、Level、復習日、設定 |
| IndexedDB `images` ストア | カードIDをキーとする画像Blob |
| localStorage `wordRecall.wordSort.v05` | 単語管理の並び替え設定 |

v0.7.7と同じDB名、DBバージョン、ストア名、データ形式、カードIDおよび画像キーを使用します。今回の更新専用のデータ移行、初期化、再登録、再インポートは不要です。既存の画像分離処理と、未入力の日本語赤字箇所のみを補う従来処理も維持しています。

単語の追加・編集・削除、一括登録（履歴を残した更新/スキップ）、並び替え、成績画面、画像を含むJSONバックアップ・復元機能を維持しています。

**重要：** データは利用中の端末・ブラウザ・オリジン（スキーム・ホスト・ポート）に保存されます。同じGitHub PagesのURL・端末・ブラウザを使って更新してください。別端末や別オリジンには自動同期されません。ブラウザのサイトデータ削除、プライベートブラウズ、端末故障等に備えて、更新前にバックアップJSONを保存することを推奨します。バックアップ作成は予防策であり、通常の更新に復元操作は不要です。

## PCでローカルテストする（Windows）

1. 全ソースZIPを解凍し、`index.html` と `start-local.bat` が同じフォルダにあることを確認します。
2. Python 3をインストール済みのPCで `start-local.bat` をダブルクリックします。
3. ブラウザで `http://localhost:8000/` を開きます。先にブラウザが開いて接続エラーになった場合は、サーバーが起動してから再読み込みしてください。
4. ローカル版は公開版とは別の保存領域です。テストカードを登録するか、任意でバックアップJSONのコピーをローカル版に復元し、動作を確認します。公開版やiPhone側の登録データは変更されません。
5. 終了時はコマンドプロンプトで Ctrl+C を押します。

手動起動の場合、解凍先のフォルダでターミナルを開き、次を実行します。

```bash
python -m http.server 8000
```

Windowsで `python` が使えない場合は `py -m http.server 8000` でも起動できます。`index.html` の直接ダブルクリックではなくHTTP経由を推奨します。

## GitHub Pagesの更新手順

1. 現在の公開版のバックアップ画面でJSONを書き出します（推奨）。
2. 更新用4ファイルZIPを解凍します。
3. 現在のGitHubリポジトリの公開フォルダ（既存の `index.html` がある場所）で、下の4ファイルを同時に上書きしてコミットします。
   - `index.html`
   - `app.js`
   - `styles.css`
   - `README.md`
4. `ui-v0.6.js` など既存ファイルは削除しないでください。並び替え等は既存の `ui-v0.6.js` を引き続き参照します。
5. GitHub Pagesのデプロイ完了を確認し、従来と同じ公開URLを再読み込みします。ヘッダーに `v0.7.8` と表示されます。CSS・JS参照にもバージョンを付与してあります。
6. 登録数・画像・成績を確認してから、10問設定で学習してください。正常なら復元は不要です。サイトデータ消去は行わないでください。

## 検証範囲

- Node.jsでJavaScript構文チェックを実施。
- 旧版のデータ構造で作成した710枚の模擬カード・画像Blob・localStorage設定を使い、Node.js VM上でDOM・IndexedDB・音声・時刻を模擬し、実際のアプリコードを実行して検証しました。
- 0秒待機、即時進行、固定10枚、正解除外、不正解だけの再出題、無制限の周回、終了、二重判定、共通集計、保存・再読み込み、読み込み失敗時の保護を確認しました。
- 実ブラウザのローカルHTTPアクセスは検証環境の管理ポリシーにより制限されていたため、実際のIndexedDBエンジン、音声出力、iPhone実機のキーボード、GitHubへのデプロイは未検証です。実機の登録データはソースZIPに含まれていないため、直接の検証対象ではありません。
- 全ソースZIPには再現用テスト `tests/regression.cjs` を収録しています。Node.js 18以上を用意し、旧v0.7.7の解凍フォルダを指定して `node tests/regression.cjs . "旧版フォルダのパス"` で実行できます。
