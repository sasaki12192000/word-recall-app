# Word Recall

日本語のコアイメージ + 画像から英単語を想起することを中心にした、GitHub Pages対応の英単語学習Webアプリです。

## 主な機能

- 1️⃣ Recall：コアイメージ + 画像 → 英単語を手入力
- 2️⃣ Use：日本語例文 → ターゲット単語を使って英文入力
- 3️⃣ Connect：意味が近い単語を選択肢から選ぶ
- 3つの学習モード
  - 単語集中：1️⃣のみ
  - 標準学習：1️⃣ + 2️⃣
  - 深掘り学習：1️⃣ + 2️⃣ + 3️⃣
- 単語・コアイメージ・画像・例文・類義語問題の登録/編集
- Recallを中心にした復習スケジュール
- 間違えた単語は5〜10問後に再出題
- 回答時間を記録
- Recall / Use / Connect の成績を別管理
- JSONバックアップ / 復元
- スマートフォン対応

## 復習間隔（初期版）

Level 0〜7を持ち、1️⃣ Recall 正解時にレベルを上げます。

- Lv0: 当日
- Lv1: 1日後
- Lv2: 3日後
- Lv3: 7日後
- Lv4: 14日後
- Lv5: 30日後
- Lv6: 60日後
- Lv7: 120日後

Recallで不正解になるとレベルを2段階下げ、当日中の再出題候補に入ります。

## 2️⃣ Use の判定について

この初期版はGitHub Pagesだけで動くサーバーレス構成なので、AIによる英文意味判定は行いません。

- 模範解答または登録した別解と一致 → 正解
- ターゲット単語を含むが完全一致しない → 「ほぼ正解」として模範解答を表示し、ユーザー自身が「正解扱い / 不正解」を選択
- ターゲット単語を含まない → 不正解

将来、AI APIを安全なバックエンド経由で接続すれば、自然な英文の意味判定に拡張できます。

## データ保存

データはブラウザの `IndexedDB` に保存されます。登録画像は自動的に最大辺1200px程度へ縮小・圧縮して保存するため、一般的な `localStorage` より大量の単語・画像を扱いやすい構成です。端末やブラウザによって保存容量には差があります。

端末変更やブラウザデータ削除に備え、「バックアップ」タブからJSONを書き出してください。

## GitHub Pagesで公開する方法

1. GitHubで新しいRepositoryを作成
2. このフォルダ内の `index.html` `styles.css` `app.js` `README.md` をRepository直下へアップロード
3. GitHubの `Settings` → `Pages`
4. `Build and deployment` の Source を `Deploy from a branch`
5. Branch を `main` / `(root)` に設定して Save
6. 表示されたGitHub Pages URLをiPhone/PCで開く

iPhoneではSafariの共有メニューから「ホーム画面に追加」すると、アプリに近い感覚で利用できます。

## v0.3: 単語の一括登録

「単語管理」→「一括登録」から、Word Recall用のJSONファイルを読み込めます。
JSONには英単語、品詞、日本語コアイメージ、画像（data URL）、USE/CONNECT用データをまとめて含められるため、1語ずつ手入力する必要はありません。

同じ英単語がすでに登録されている場合は、次のどちらかを選べます。
- 学習履歴を残して内容だけ更新
- 既存単語を残してスキップ

一括登録は「バックアップから復元」と違い、現在の単語を消さずに追加します。


## v0.3 一括登録の変更

- 一括登録ボタンは native `<dialog>` を使わず、直接ファイル選択を開く方式に変更しました。
- ファイル選択後、単語管理画面内にプレビューが表示されます。
- 一括登録JSONは以下をすべて含められます。
  - `word` / `pos` / `core` / `image`
  - 2️⃣ USE: `sentenceJa` / `sentenceEn` / `alternatives`
  - 3️⃣ CONNECT: `choices` / `correctChoice` / `connectExplanation`
- プレビューで「画像」「USE」「CONNECT」が何件入っているか確認できます。
- `index.html` は `app.js?v=0.3` / `styles.css?v=0.3` を参照し、GitHub Pages更新時の古いキャッシュを避けます。
