Word Recall v0.5 UI update
===========================

変更内容
1. 単語管理に並び替えを追加
   - アルファベット順
   - 登録順
   - Recall正解率順
   - すべて昇順 / 降順を切り替え可能
2. 解答後の「次へ / 次の単語」ボタンを横長・大きめに変更
   - iPhoneで押しやすいサイズ

GitHubでの更新方法
1. Repositoryのルートに、このZIP内の index.html を既存ファイルへ上書きアップロード
2. 同じ場所に ui-v0.5.js を新規アップロード
3. Commit changes
4. GitHub Pagesを再読み込み

既存の app.js / styles.css / IndexedDB内の単語データは変更しません。
そのため、登録済み単語・学習履歴・画像はそのまま残ります。

並び替えの定義
- アルファベット順: A→Z / Z→A
- 登録順: 古い→新しい / 新しい→古い
- Recall正解率順: 低い→高い / 高い→低い

※ Recall未回答の単語は正解率0%として扱います。

[v0.6.1 Recall answer enhancement]
Recallの正誤表示（記憶を固定）画面に、登録データの「模範英文」（sentenceEn）を追加表示。
模範英文が未登録の単語ではこの欄を自動的に非表示。既存データ・画像・学習履歴の形式変更なし。
